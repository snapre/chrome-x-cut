# Photos 相册指定功能设计

## 目标

允许用户在扩展弹窗中填写一个 macOS Photos 普通相册名称。保存图片时，扩展将原图导入该相册；名称留空时维持现状，只导入 Photos 图库。

## 方案

采用“单个默认相册名称”的轻量设置，而不是读取 Photos 相册列表或每次保存时弹窗选择。这个方案不需要扩展读取用户的 Photos 数据，也不会增加额外权限。设置保存在 `chrome.storage.sync`，后台保存流程把相册名称作为 native messaging 参数传给本机 helper。

本机 helper 对相册名称进行类型、长度和控制字符校验，并把名称作为独立的 `osascript` 参数传入，避免把用户输入拼接进 AppleScript。Photos 中不存在同名普通相册时自动创建；存在时复用。图片仍会进入 Photos 图库，相册只增加组织关系。相册名称留空时执行原有导入命令。

## 错误处理与验证

- 非字符串、超过 100 个字符或包含控制字符的相册名称会返回明确错误。
- Photos 创建相册或导入失败时，继续通过现有按钮错误状态反馈。
- Python 单元测试覆盖名称校验、空相册导入和指定相册导入命令。
- 现有 JavaScript 语法检查和 URL 工具测试继续运行。
