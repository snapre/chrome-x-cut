# Threads 小图模式命中修复

Threads 信息流的小图卡片会把 `<picture>` 包在可点击的父级 `div` 中。浏览器的 `elementsFromPoint()` 返回这个父级覆盖层，而不是 `<img>` 或 `<picture>`。现有逻辑只接受“图片包含命中元素”，因此错误地忽略小图。

修复保持原有图片尺寸、可见区域、官方 CDN URL 和鼠标坐标矩形校验，只把节点关系从单向扩展为双向：命中元素是图片的子节点，或命中元素包含图片时，都视为同一媒体。这样不依赖 Threads 的动态 class，也不会把图片矩形之外的帖子文字区域识别成图片。

验证包括完整自动化测试，以及在实际 Threads 信息流中把鼠标移动到小图中央，检查 `Cut` 按钮进入可见状态并定位到对应图片。
